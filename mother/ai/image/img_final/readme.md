How to Flash the Image to the AI-G Board

1. Download the image file from the Google Drive link provided above.
https://drive.google.com/file/d/1azhOJtnr9xlVGqcZu36lLXPdkeiO-3wM/view?usp=sharing

2. After downloading, extract the file if it is compressed.

3. Connect the AI-G board to your PC.

4. Run the following command inside the extracted folder:

```.\fwdn_ai.bat```


5. Follow the on-screen instructions to flash the image to the board.

Make sure the board is properly connected before running the script.
